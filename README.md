# A股短线选股器 V1.0（手机网页 + 本地研究工具）

## 手机网页
- 单页响应式网页，适配手机和桌面浏览器。
- 通过浏览器请求东方财富公开行情接口，尝试获取沪深 A 股列表。
- 展示价格、涨跌幅、换手率、量比和基于量价字段的观察评分。
- 支持市场范围、涨跌幅条件、排序筛选。
- 内置单笔风险预算/股数估算器，默认风险上限为账户权益的 0.75%。
- 行情失败时明确提示，不用模拟行情填充。

## 本地历史行情与回测
需要安装 Python 3.10+，然后在仓库目录执行：

```bash
pip install -r requirements.txt
python fetch_history.py --codes 000001,600000,000858 --start 20230101 --end 20261028 --out data/daily_bars.csv
python backtest.py data/daily_bars.csv --stop 0.05 --target 0.08 --max-hold 5 --out data/backtest_trades.csv
```

也可以将股票代码每行写入 `codes.txt`，使用 `--codes-file codes.txt`。历史行情由 AkShare 运行时请求第三方数据接口获取；接口可能限流或变更，下载失败会打印错误，不会用虚构数据补齐。先用少量股票测试，再扩大范围。当前下载脚本默认使用前复权日线（qfq）；务必记录数据口径，避免混合不同复权方式。

## 当前策略和回测的边界
- 网页上的即时分数仍是简化的行情观察分数，不是完整的基本面模型或买入建议。
- `backtest.py` 当前是透明的基线示例：收盘价高于 MA20 且当日涨跌幅在 -3% 到 +2% 之间；信号在收盘后形成，下一交易日开盘入场。
- 基线回测暂未计入手续费、滑点、涨跌停无法成交、停牌、复权除权执行细节及组合层面的资金冲突；最大回撤是按交易序列收益计算的简化指标，并非完整账户权益曲线。
- 尚未在本次提交中实际下载行情或执行历史回测；不要把示例代码当成已验证的策略，也不要引用未经运行的胜率/收益数字。
- 完整“主线题材 + 业绩稳健 + 主升后首次回调”模型仍需接入可追溯的题材与按公告时间对齐的基本面数据。
