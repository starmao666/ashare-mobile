# A股短线选股器 V1.0（手机网页）

## 当前版本
- 单页响应式网页，适配手机和桌面浏览器。
- 通过浏览器请求东方财富公开行情接口，尝试获取沪深 A 股列表。
- 展示价格、涨跌幅、换手率、量比和基于量价字段的观察评分。
- 支持市场范围、涨跌幅条件、排序筛选。
- 行情失败时明确提示，不用模拟行情填充。

## 重要限制
- 评分仅为技术面观察筛选，不是完整基本面模型或买入建议。
- 尚未实现历史回测；没有经验证的胜率、收益或回撤数据。
- 第三方接口可能限流、延迟或因浏览器跨域策略不可用。
- 不构成投资建议。

## Render 部署
仓库包含 `render.yaml`，在 Render 中选择 New > Blueprint 并连接此仓库，按配置创建静态站点。部署后使用 Render 提供的真实 URL 访问。
